# Four acceptance exercises

- Today: one step, dated money, existing plan remains stable; missing inputs produce useful clarification. Information control is discoverable and labelled.
- Add income: show current account balance/date, included/not included/unsure choice; pending/retry/conflict cannot double-add; keyboard and large text remain usable.
- Import error: explain cause with next action; preserve selected context and corrections; partial extraction is explicit; no financial mutation.
- Explanation: open the right recommendation in Assistant; show changed version if stale; evidence available; scenario text cannot silently write finances.

For each record task completion, observed confusion, build/device and real failures. Do not fabricate timings or claim user acceptance from code inspection.
