## Что сделано
- Создан автономный модуль `services/api/vela/pii.py` без изменения `ai.py`/`imports.py`/`chat.py`:
  - `is_pii_masking_enabled() -> bool`: проверяет переменную окружения `PII_MASKING` (по умолчанию `True`, отключается только при значениях `false`, `0`, `no`, `off`).
  - `is_valid_iban(raw: str) -> bool`: валидация международного номера банковского счёта по алгоритму ISO 7064 MOD 97-10 (`int(digits) % 97 == 1`), длина 15–34 символов, корректный код страны и контрольные цифры.
  - `is_valid_luhn(card_number: str) -> bool`: валидация номеров платёжных карт (PAN) алгоритмом Луна (Luhn) для диапазонов 13–19 цифр, исключающая строки из одних нулей или с ведущим нулем.
  - `mask_pii(text: str, *, force: bool = False) -> str`: заменяет PII-сущности на метки:
    - **IBAN** (с пробелами или без, прошедший проверку `mod 97 == 1`) → `[REDACTED_IBAN]`.
    - **Номера банковских карт** (13–19 цифр подряд, через пробел или дефис в группах по 4 или формате Amex 4-6-5, прошедшие проверку алгоритмом Луна) → `[REDACTED_CARD]`.
    - **Email-адреса** → `[REDACTED_EMAIL]`.
    - **Телефоны** (международные форматы `+XX...` или `00XX...`, от 9 до 15 цифр, с защитой от искажения дат `2026-03-15`, `15.03.2026` и сумм `-125,40 EUR`, `+100.00 EUR`, `2400.00`) → `[REDACTED_PHONE]`.
    - **Заголовки ФИО и адреса в шапке выписки** (префиксы `Account holder:`, `Kontoinhaber:`, `Владелец счёта:`, `Address:`, `Adresse:`, `Адрес:`) → префикс + `[REDACTED_NAME]` / `[REDACTED_ADDRESS]`.
    - Поддерживает флаг `force=True` для принудительного маскирования даже при временно отключённом `PII_MASKING`.
  - `mask_pii_lines(lines: Sequence[str], *, force: bool = False) -> list[str]`: пакетное маскирование последовательности строк.
- Создан тестовый модуль `services/api/tests/test_pii.py` (9 тестов):
  - `test_iban_validation`: валидация корректных IBAN (DE, FR, GB, NL, ES), отклонение невалидных контрольных сумм и коротких строк.
  - `test_luhn_validation`: проверка валидных карт Visa, Mastercard, Amex, Мир, отклонение невалидных сумм и всех нулей.
  - `test_flag_defaults_to_true`, `test_flag_can_be_disabled`, `test_mask_pii_respects_flag`: проверка чтения конфигурации из окружения и сохранения исходного текста при отключении.
  - `test_corpus_count_at_least_20`: проверка наличия ≥ 20 строк выписок (фактически 25 строк).
  - `test_corpus_no_pii_leaks_and_preserves_financial_data`: проверка корпуса из 25 реалистичных строк выписок на немецком, английском и русском языках (DE/EN/RU). Проверено, что 0 валидных IBAN, карт Luhn, email, телефонов или данных заголовков не утекает в вывод, а финансовые суммы (`-125,40 EUR`, `2400.00`, `-850,00`, `+3200.00 EUR`, `2.500,00`), даты (`2026-03-01`, `15.03.2026`, `01.10.2026`) и названия мерчантов (`REWE Markt`, `Spotify UK`, `Netflix Subscription`, `ACME GmbH`, `Hausverwaltung Meier`, `Yandex Food`) остаются неповреждёнными.
  - `test_mask_pii_lines`: пакетная обработка строк.
  - `test_multiline_csv_preserves_structure`: проверка многострочного документа банковской выписки CSV.
